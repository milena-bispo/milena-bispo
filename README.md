## 📊 Projeto em destaque

### Dashboard de Investimentos

Dashboard desenvolvido no Power BI a partir de uma base em Excel com dados reais de uma carteira de investimentos, utilizados com autorização do titular.

O painel apresenta:
- Patrimônio atual da carteira
- Valor aplicado no Tesouro Direto
- Quantidade de ativos e instituições
- Distribuição do patrimônio por categoria
- Ranking dos 10 maiores ativos por patrimônio

Trabalhei com organização e tratamento dos dados, criação de medidas em DAX, validação dos indicadores e construção da identidade visual.

**Principal aprendizado:** durante a validação, identifiquei que o valor originalmente aplicado estava disponível apenas para o Tesouro Direto. Ajustei o indicador para evitar uma interpretação incorreta da rentabilidade total da carteira.
